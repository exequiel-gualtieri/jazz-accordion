# Changelog

## 1.0.0

First public release.

- `<jazz-accordion>` and `<jazz-accordion-item>` Web Components, zero dependencies.
- WAI-ARIA accordion pattern, keyboard navigation, configurable heading level.
- Single, multiple and always-open modes; disabled items.
- Print support: `print="expanded | collapsed | as-is"`.
- Find-in-page for closed panels (`hidden="until-found"`).
- Interruptible height animation honouring `prefers-reduced-motion`.
- Search with accent-insensitive filtering and highlighted matches.
- Deep linking, localStorage persistence, lazy `<template>` content.
- schema.org FAQPage JSON-LD output.
- Nine themes: dark, hud, glass, minimal, terminal, corporate, brutalist, neon, paper.
- TypeScript definitions.
