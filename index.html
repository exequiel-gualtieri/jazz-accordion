Most accordions fail at the basics

They hide content from printers, from Ctrl+F, from keyboards and from search engines. Jazz Accordion fixes each of these.

print

Prints what's hidden

Closed panels are printed expanded by default. Choose expanded, collapsed or as-is per accordion or item.

ctrl+f

Find-in-page

Uses hidden="until-found", so the browser finds text inside closed panels and opens them automatically.

a11y

Accessible by default

WAI-ARIA accordion pattern, ↑ ↓ Home End navigation, real heading levels, focus rings and forced-colors support.

#hash

Deep links

/faq#refunds opens that question, even inside nested accordions. Clicking an item updates the URL.

search

Built-in search

Accent-insensitive filtering with highlighted matches (CSS Custom Highlight API), announced to screen readers.

seo

FAQ rich results

faq-schema generates schema.org FAQPage JSON-LD from your items.

motion

Smooth, interruptible

Height animation you can interrupt mid-way. Turns itself off with prefers-reduced-motion.

secure

CSP & Trusted Types

No innerHTML, no inline styles. Constructable stylesheets work under a strict Content Security Policy.

lazy

Lazy content

Wrap heavy content in a <template> and it renders on first open, or just before printing.

persist

Remembers state

persist="key" restores open panels on the next visit, and fails safely if storage is blocked.

any

Any framework

React, Vue, Angular, Svelte, Astro, WordPress or plain HTML. It's a standard custom element.

rtl

RTL & i18n

Logical CSS properties throughout, and every UI string can be set with an attribute.

Install in 10 seconds

No build step. Paste two tags, or install from npm.

1 · Script (CDN)
<script src="https://cdn.jsdelivr.net/npm/jazz-accordion@1/dist/jazz-accordion.min.js"></script>
2 · Theme (optional)
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/jazz-accordion@1/dist/themes/hud.css" />
or npm
npm install jazz-accordion

import 'jazz-accordion';
import 'jazz-accordion/themes/hud.css';
3 · Use it
<jazz-accordion theme="hud" multiple>
  <jazz-accordion-item label="What is it?" open>
    An accordion that just works.
  </jazz-accordion-item>
  <jazz-accordion-item label="Does it print?">
    Yes, closed panels included.
  </jazz-accordion-item>
</jazz-accordion>

API reference

        
Attributes set on <jazz-accordion> are inherited by its items. Items can override them individually.


        
<jazz-accordion> attributes

        

          
AttributeValuesDescription

          
            
multiplebooleanAllow several panels open at once.

            
always-openbooleanAt least one panel stays open; its header gets aria-disabled.

            
themenameTheme to apply (load its CSS file).

            
indicatorchevron plus arrow noneExpand/collapse icon. Themes can set it with --jz-indicator.

            
indicator-positionstart endSide of the icon.

            
heading-level1–6 (3)aria-level of the headers, so they fit your document outline.

            
printexpanded collapsed as-isWhat gets printed. Default: expanded.

            
no-animationbooleanDisable the height animation.

            
searchbooleanShow a filter box with highlighted matches.

            
controlsbooleanShow Expand all / Collapse all (with multiple).

            
deep-linkbooleanOpen the item whose id matches location.hash.

            
persistkeyRemember open items in localStorage.

            
faq-schemabooleanEmit schema.org FAQPage JSON-LD for rich results.

            
search-label search-placeholder expand-label collapse-label results-label no-results-labeltextTranslations. results-label accepts {count}.

          
        


        
<jazz-accordion-item>

        

          
Attribute / slotDescription

          
            
labelHeader text. Rendered as text, never as HTML.

            
subtitleSecondary line under the header.

            
openOpen state, reflected both ways.

            
disabledThe user cannot toggle it. It stays focusable so screen readers can find it.

            
lazyRender the inner <template> on first open (or before printing).

            
titleLegacy alias of label; removed after reading so no tooltip appears.

            
slot="title" slot="subtitle" slot="icon"Rich header content.

Create your own theme

        
jazz-accordion[theme='brand'] {
  --jz-accent: #e11d48;
  --jz-radius: 1rem;
  --jz-header-bg-open: #e11d48;
  --jz-header-color-open: white;
  --jz-indicator: plus;
}
/* structural tweaks */
jazz-accordion[theme='brand'] > jazz-accordion-item::part(title) {
  font-variant: small-caps;
}
